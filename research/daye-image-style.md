# 다예 생성 사진 기준

사용자 요청: 2026-10-07. 쇼핑 커넥트 사용 장면과 이후 인물 사진에 적용한다.

최신 배치 선호: 제목 바로 아래에 본문 사진을 먼저 둔다. 한 글에는 서로 다른 본문 사진을 최소 5장 사용하며 별도 썸네일은 개수에 포함하지 않는다. 기존 소주제 바로 아래 사진은 유지하고, 반복 사진으로 개수를 채우지 않는다.

최종 사용자 교정: 얼굴을 빼라는 뜻이 아니라 '얼굴이 꼭 나와야 한다'는 전제로 만들지 말라는 뜻이다. 사용자가 승인한 카트·휴대폰·헤드폰 예시처럼 사용 장면 속에 자연스러운 얼굴이 보이는 사진은 좋다. 얼굴 노출·비노출을 일괄 강제하지 않고 동작과 구도에 맞춰 선택한다. 원래의 낮은 선명도·생활 스냅 질감·사진마다 서로 다른 옷 기준은 유지한다. 이 기준을 앞선 '모두 얼굴을 화면 밖에 둔다'는 해석보다 우선한다.

실제 사진 비교에서 볼 점: 사용자 거울 사진과 케넨 2026-09-20 스탠바이미 사진 두 장을 나란히 확인했다. 실제 사진은 피사체가 화면 가장자리에서 잘리고, 실내 빛이 균일하지 않으며, 제품 표면과 배경이 과도하게 선명하지 않고 바닥·선·생활 물건이 그대로 보인다. 생성물의 정돈된 화분·균일한 피부·광고 같은 배경 흐림·머리카락의 과한 디테일을 줄인다. 해당 블로그 사진은 비교만 하고 전달용 원고에 재사용하지 않는다.
비교 출처: https://blog.naver.com/teemogogo/224417741509 (IMG＿6338.JPG, IMG＿6329.JPG). 촬영 원본 메타데이터를 검증한 것은 아니며 블로그에 실생활 사용 장면으로 게시된 사진을 비교했다.

작업 기준: 약 600~750px 사진을 공유했을 때의 부드러운 세부 묘사, 약한 흔들림·압축감, 평범한 조명과 살짝 비뚤어진 생활 구도. 거칠게 망가뜨리기보다 제품을 알아볼 수 있는 정도는 유지한다. 자연스러운 얼굴 구도에는 아래 인물 참조를 쓰고, 손 중심 동작에는 얼굴을 억지로 추가하지 않는다. 얼굴이 자연스럽게 보이는 사진을 굳이 잘라내지도 않는다.

- 사람이 등장하면 한국 여성으로 만든다. 손과 몸만 보이는 장면도 여성의 자연스러운 손·체형·옷차림으로 맞춘다.
- 얼굴이 보일 때는 사용자가 직접 제공한 본인 사진을 이미지 참조로 사용한다. 짙은 머리와 앞머리, 일상 사진 속 자연스러운 인상을 반영한다. 모든 사진을 프로필 촬영처럼 만들지 않는다.
- 실내 거울 셀카, 행사 야간 스냅, 차창 반사 사진은 생활 구도와 사진 질감의 참조다. 증명사진은 얼굴 참조이며, 증명사진의 보정과 조명을 일상 장면에 그대로 옮기지 않는다.
- 아이폰 17로 가볍게 찍어 공유한 듯한 사진: 적당한 해상도감, 부드러운 세부 묘사, 약한 입자감, 자연스러운 노출과 빛, 과하지 않은 색감. 손과 피부의 모공을 과장하지 않고 눈·얼굴·제품 가장자리를 지나치게 선명하게 만들지 않는다.
- 인위적인 광고 배경, 스튜디오 조명, 플라스틱 피부, 과도한 얼굴 보정, 강한 배경 흐림, 균일한 패턴을 피한다. 사람과 제품 모두 실제로 가능한 자세와 형태를 확인한다.
- 상품별로 손동작·생활 맥락을 바꾸며 같은 인물의 같은 포즈를 반복하지 않는다. 제품은 판매자 참조를 함께 사용한다.
- 생성 결과는 AI 사용 장면으로 표시한다. 실제 다예의 체험이나 제품 효과 증거로 사용하지 않는다.
