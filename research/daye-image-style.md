# 다예 생성 사진 기준

## 2026-10-08 최종 프롬프트 — 긴머리·얼굴 참조 역할 분리

사용자가 집에서도 같은 인물과 사진 느낌으로 제작하도록 최종 프롬프트의 동기화를 요청했다. 실제 정면 사진은 단발이므로 얼굴만 참고하고 머리는 실제 긴머리 일상 사진을 기준으로 한다. 마음에 든 긴머리 생성 사진을 결과 예시로 함께 제공해도 되지만 얼굴의 기준은 실제 원본이다. 원본 얼굴 사진이나 생성 예시는 Git에 추가하지 않는다.

### 복사용 최종 프롬프트

첨부한 실제 사진 속 사람이 나, 다예야. 내가 등장하는 여행 이미지는 제공한 얼굴 사진을 참고하고, 옷·동작·구도를 달리해 자연스러운 아이폰 여행 사진 느낌으로 만들어줘.

사진별 참고 역할은 다음과 같아.
- 정면 단발 사진: 얼굴 윤곽과 눈·코·입의 모양, 비율만 참고해줘. 단발머리는 따라 하지 마.
- 실제 긴머리 일상 사진: 짙은 긴머리와 자연스러운 앞머리, 평소 인상을 참고해줘.
- 거울 셀카와 야간 사진: 자연스러운 빛·색감·피부 질감·선명도와 생활 구도를 참고해줘.
- 마음에 들었던 생성 사진: 원하는 결과의 분위기와 인물 표현 예시야. 얼굴의 기준은 실제 사진으로 유지해줘.

[장소]에서 [행동] 중인 나를 여행 동행인이 아이폰 기본 카메라로 가볍게 찍은 듯한 AI 여행 사진으로 만들어줘. [시간대·날씨]에 맞는 자연광과 현실적인 현장 디테일을 반영해줘.

얼굴의 특징과 자연스러운 신체 비율을 유지하고, 다른 사람처럼 바꾸거나 과하게 미화하지 마. 정면 사진의 증명사진 조명과 매끈한 보정은 가져오지 마.

아이폰으로 찍어 공유한 일상 사진처럼 세부 묘사는 부드럽게, 색감과 스마트폰 HDR은 자연스럽게 해줘. 약한 흔들림·입자감·압축감과 불균일한 빛을 적당히 반영하되 일부러 흐리거나 화질을 망가뜨리지는 마. 지나치게 선명한 피부·머리카락, 강한 배경 흐림과 과도한 보정은 피해주세요.

사진마다 옷의 색·종류·소재, 행동, 촬영 거리와 각도를 달리해줘. 옷은 장소·날씨·활동에 맞게 입혀줘. 걷기·구경하기·쉬기·책 읽기처럼 장면 속 행동이 자연스럽게 이어지도록 해줘.

얼굴을 보여주기 위한 정면 포즈만 반복하지 마. 옆모습·뒷모습·비스듬한 시선도 활용하고 얼굴 노출을 일괄 강제하지 마. 살짝 비뚤어지거나 가장자리가 잘리는 평범한 여행 스냅 구도도 좋아.

광고컷·화보컷·3D 렌더·AI 일러스트 같은 느낌, 완벽한 대칭 구도와 비현실적인 조명은 피해주세요. 손·몸·물체의 형태와 원근은 자연스럽게 만들고, 실제 장소의 특징을 임의로 바꾸지 마. 특정 숙소의 객실이나 시설을 확인하지 않았다면 실제 시설과 일치한다고 가정하지 마.

한 장씩 독립된 사진으로 만들고 콜라주·글씨·로고는 추가하지 마.

## 2026-10-08 최신 추가 — 아이폰 기본 카메라 여행 기록사진 질감

사용자가 제시한 사진 프롬프트와 제작 기준을 이후 여행 사진에 적용한다. 실제 사진처럼 자연스러운 시각적 질감을 뜻하며 AI 제작물을 실제 방문·촬영 증거로 주장하지 않는다. 기존 인물 참조·사진별 옷 다양화·얼굴 노출을 강제하지 않는 기준도 유지한다.

### 사용자 사진 프롬프트

> [장소]에서 [상황] 중 [피사체]를 일반 여행자가 아이폰 기본 카메라로 직접 촬영한 실제 여행 기록사진처럼 만들어줘. [시간대/날씨]의 자연광과 [구도]를 반영하고, 과보정 없는 [색감], 자연스러운 스마트폰 HDR, 스마트폰 특유의 현실적인 질감이 느껴지게 해줘. [현장 디테일]이 자연스럽게 보이도록 하고, 생활감 있는 프레이밍과 즉흥적인 분위기가 느껴지게 해줘. 광고컷, 화보컷, 3D 렌더, 과한 보정, 비현실적인 조명, 지나치게 완벽한 구도, AI 일러스트 느낌은 나지 않게 해줘.

제작 기준: 일반 여행자의 기록사진 같은 아이폰 기본 카메라 질감, 자연광·자연스러운 스마트폰 HDR·과보정 없는 색감, 즉흥적이고 완벽하지 않은 현실적인 프레이밍, 현장 디테일과 생활감. 광고컷·화보컷·3D 렌더·AI 일러스트 느낌을 피한다. HDR를 과도한 선명도·강한 대비·피부 보정으로 해석하지 않으며 기존의 부드러운 세부 묘사와 약한 흔들림·압축감 기준을 함께 적용한다.

사용자 예: 부산 해운대 바닷가 앞을 걸을 때 횡단보도를 스쳐 지나가는 택시, 오전 10시 흐린 날 자연광. 장소·시간·행동에 맞는 배경과 생활 디테일을 담고 과도하게 완벽한 광고 구도는 피한다.

사용자 요청: 2026-10-07. 쇼핑 커넥트 사용 장면과 이후 인물 사진에 적용한다.

최신 배치 선호: 제목 바로 아래에 본문 사진을 먼저 둔다. 한 글에는 서로 다른 본문 사진을 최소 5장 사용하며 별도 썸네일은 개수에 포함하지 않는다. 기존 소주제 바로 아래 사진은 유지하고, 반복 사진으로 개수를 채우지 않는다.

최종 사용자 교정: 얼굴을 빼라는 뜻이 아니라 '얼굴이 꼭 나와야 한다'는 전제로 만들지 말라는 뜻이다. 사용자가 승인한 카트·휴대폰·헤드폰 예시처럼 사용 장면 속에 자연스러운 얼굴이 보이는 사진은 좋다. 얼굴 노출·비노출을 일괄 강제하지 않고 동작과 구도에 맞춰 선택한다. 원래의 낮은 선명도·생활 스냅 질감·사진마다 서로 다른 옷 기준은 유지한다. 이 기준을 앞선 '모두 얼굴을 화면 밖에 둔다'는 해석보다 우선한다.

실제 사진 비교에서 볼 점: 사용자 거울 사진과 케넨 2026-09-20 스탠바이미 사진 두 장을 나란히 확인했다. 실제 사진은 피사체가 화면 가장자리에서 잘리고, 실내 빛이 균일하지 않으며, 제품 표면과 배경이 과도하게 선명하지 않고 바닥·선·생활 물건이 그대로 보인다. 생성물의 정돈된 화분·균일한 피부·광고 같은 배경 흐림·머리카락의 과한 디테일을 줄인다. 해당 블로그 사진은 비교만 하고 전달용 원고에 재사용하지 않는다.
비교 출처: https://blog.naver.com/teemogogo/224417741509 (IMG＿6338.JPG, IMG＿6329.JPG). 촬영 원본 메타데이터를 검증한 것은 아니며 블로그에 실생활 사용 장면으로 게시된 사진을 비교했다.

작업 기준: 약 600~750px 사진을 공유했을 때의 부드러운 세부 묘사, 약한 흔들림·압축감, 평범한 조명과 살짝 비뚤어진 생활 구도. 거칠게 망가뜨리기보다 제품을 알아볼 수 있는 정도는 유지한다. 자연스러운 얼굴 구도에는 아래 인물 참조를 쓰고, 손 중심 동작에는 얼굴을 억지로 추가하지 않는다. 얼굴이 자연스럽게 보이는 사진을 굳이 잘라내지도 않는다.

- 사람이 등장하면 한국 여성으로 만든다. 손과 몸만 보이는 장면도 여성의 자연스러운 손·체형·옷차림으로 맞춘다.
- 얼굴이 보일 때는 사용자가 직접 제공한 본인 사진을 이미지 참조로 사용한다. 짙은 머리와 앞머리, 일상 사진 속 자연스러운 인상을 반영한다. 모든 사진을 프로필 촬영처럼 만들지 않는다.
- 실내 거울 셀카, 행사 야간 스냅, 차창 반사 사진은 생활 구도와 사진 질감의 참조다. 증명사진은 얼굴 참조이며, 증명사진의 보정과 조명을 일상 장면에 그대로 옮기지 않는다.
- 아이폰 17로 가볍게 찍어 공유한 듯한 사진: 적당한 해상도감, 부드러운 세부 묘사, 약한 입자감, 자연스러운 노출과 빛, 과하지 않은 색감. 손과 피부의 모공을 과장하지 않고 눈·얼굴·제품 가장자리를 지나치게 선명하게 만들지 않는다.
- 인위적인 광고 배경, 스튜디오 조명, 플라스틱 피부, 과도한 얼굴 보정, 강한 배경 흐림, 균일한 패턴을 피한다. 사람과 제품 모두 실제로 가능한 자세와 형태를 확인한다.
- 상품별로 손동작·생활 맥락을 바꾸며 같은 인물의 같은 포즈를 반복하지 않는다. 제품은 판매자 참조를 함께 사용한다.
- 생성 결과는 AI 사용 장면으로 표시한다. 실제 다예의 체험이나 제품 효과 증거로 사용하지 않는다.
