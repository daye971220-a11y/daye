## 브라우저 작성 작업에서 확인한 방법

- 집에서는 현재 설치된 computer-use SKILL을 먼저 읽고 해당 컴퓨터의 브라우저 목록을 새로 확인한다. 회사 탭 ID를 집에 재사용하지 않는다.
- 한국어는 `paste`로 입력한다. `typeText`로 긴 한국어를 치면 IME 잔여 문자나 오타가 생길 수 있다.
- 제목·본문을 따로 넣고 깨끗한 HTML을 붙인다. 네이버 편집 DOM을 통째로 복사하면 ‘AI 활용 설정/사진 설명/출처 입력’ 같은 편집 UI가 본문 문자로 섞일 수 있다.
- HTML `<blockquote>`는 기본 인용구가 되므로 소제목을 누른 뒤 현재 서식 도구의 **인용구2**로 각각 바꾼다. 위쪽 ‘인용구 선택’은 새 빈 인용구를 추가할 수 있다.
- HTML의 링크는 편집 DOM에서 `span.se-link[data-href]`로 바뀐다. `<a>`가 없다는 이유로 링크가 없다고 판단하지 않는다. 일반상품URL3곳은 보통span6개로 나뉜다.
- 원격 공식 사진은 붙여넣기 직후 회색 SVG로 지연 로딩됐고 이후 원본URL/naturalWidth가 확인됐다. 회색 상태에서 사진 검수 완료라고 보고하지 않는다. 저장된 글을 다시 불러와 유지되는지 확인하고 필요하면 정식 사진 업로드로 보완한다.
- 새 글은 현재 저장 완료 확인 후 해당 작업 탭을 닫고 같은 계정의 새 글쓰기 문서를 연다. ‘이어서 작성’ 복구 안내가 보이면 이전 글이 이미 저장된 경우 **취소**해 빈 문서에서 시작한다. 기존 글을 전체 교체해 다른 상품으로 덮어쓰지 않는다.
- 이 회사 브라우저는 무거운 마이리얼트립 상품 탭을 열면 간헐적으로 모든 입력이 멈췄다. 에이전트가 연 조사 탭을 닫자 회복됐다. 같은 실패를 반복하지 말고 웹 검색 도구/가벼운 판매자 원본을 사용한다. 사용자가 연 탭은 임의로 닫지 않는다.
