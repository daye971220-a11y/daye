# 경제·대학교 분석 표본 32편과 서식 관찰

확인일 2026-10-07. 열려 있던 8개 블로그에서 각 4편의 본문을 직접 읽었다. 아래 링크는 실제 관찰한 게시물이다. 분석과 향후 작성 규칙은 [경제·대학교 작성 기준](economy-blog-analysis.md)을 따른다.

## 측정값을 읽는 방법

- `텍스트`는 `.se-main-container`의 공백 제거 글자 수다. 본문에 반복된 제목·관련 글 카드·표·캡션·태그·일부 보이지 않는 구분 문자가 포함될 수 있다. 제목/태그/표 제외 순수 원고 분량이 아니므로 최소 글자 수 기준으로 사용하지 않는다.
- `사진/표/인용/스티커`는 해당 본문 컴포넌트 수다. 사진에는 말미 팬하기 이미지도 포함되며 광고·관련 카드·스티커는 별도로 구분했다. 인용에는 제목을 다시 쓴 인용과 질문도 포함돼 소제목 수와 같지 않다. 표에는 목차용 표도 포함된다.
- 글자 크기·정렬은 본문 문단과 첫 텍스트 스팬의 관찰값이다. ‘중심’은 많이 사용한 크기이고 캡션·표·링크 일부 크기가 섞일 수 있다. 색/볼드는 편집기 마크업과 계산된 스타일을 대조했으며 실제 모든 굵은 글씨를 완벽히 분류하는 수치로 취급하지 않는다.
- 상대 게시 시각(1시간 전 등)은 확인 당시 화면 그대로다. 절대 작성일/시각으로 역산하지 않는다. 본문의 정책·가격·순위가 사실인지 공식 최신 자료와 전면 대조한 기록이 아니다.
- 이번 확인 범위 밖의 과거 글, 사진의 라이선스, 실제 조회수/수익 성과는 확정하지 않았다. 원문 전문과 사진 파일을 저장하지 않는다.
