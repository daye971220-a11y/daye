# 다예 연예 블로그 홈피드와 프로필 작성 기준

2026년 10월 6일 분석. 연예 홈피드는 **지금 궁금한 사건과 장면을 먼저 설명하는 글**, 프로필은 **그 사람이 누구인지와 왜 지금 관심을 받는지를 연결하는 글**로 구분한다. 임씨의 방송 해석, 찌롱의 인물 관계 설명, 집구석 언니의 짧은 문장과 이야기형 프로필을 참고하되 다예의 최신 말투와 서식을 우선한다.

## 분석 범위와 측정 기준

### 2026-10-07 트로트 이슈·프로필과 팬 댓글

- 다예는 나주 영산강 축제 제목에 박지현·성리 이름을 적었을 때 팬 방문과 댓글이 늘었다고 공유했다. 앞으로 트로트 방송·공연·축제 이슈는 공식적으로 관련이 확인된 핵심 가수 1~2명의 이름을 제목에 자연스럽게 넣는다. 본문에서 인물별 출연일·역할·현재 소식을 설명하며 이름만 끼워 넣지 않는다.
- 마무리는 실제 출연진 중 선호·기대하는 무대 또는 듣고 싶은 곡을 짧게 묻는다. 예: ‘박지현·성리 중 누구 무대가 더 기다려지세요? 듣고 싶은 노래도 댓글로 알려주세요.’ 선호 질문은 가능하되 ‘누가 더 잘하나’ 같은 실력 서열로 바꾸지 않고 모든 글에 같은 문구를 반복하지 않는다. 공연이 끝났다면 기대형 대신 본 무대·기억에 남은 장면을 묻는다.
- 최근 이슈가 없으면 집구석 언니(homenews_) 분석처럼 최근 관심 계기→확인된 기본 정보→활동 과정→대표 무대→현재 근황 순서의 이야기형 프로필을 쓴다. 인기가 있다는 이유만으로 논란·열애 등 사건을 만들지 않는다.
- 인기 조사에는 발표일과 지표 종류를 함께 기록한다. 브랜드평판·팬 투표·음원·공연 지표를 종합 인기 순위나 가창력 순위로 바꾸지 않는다. 팬 반응이 있는 박지현·성리를 우선 검토하되 새로운 공식 이슈가 있는 다른 가수도 찾는다.
- 이번 새 트로트 원고는 사용자 요청대로 별도 검토본으로 전달한다. 사용자가 다른 블로그에 로그인 중이므로 네이버 작성·저장·발행하지 않는다. 원고·사진은 Git 보관하지 않는다.

### 다예의 사진 선택 기준 — 2026-10-06 추가

- 2026-10-07 재확인: 앞으로 모든 연예 사진 탐색은 본인 인스타그램부터 시작한다. 해당 근황의 공개 게시물을 먼저 찾고, 부족하면 구글에 인물 이름·관련 장면을 영어로 검색해 한국 매체보다 해외 출처·외국인이 올린 이미지를 우선 확인하고 캡처한다. 영문 검색 결과라는 이유만으로 해외 원출처로 단정하지 않고 실제 게시자·사진 크레딧을 확인한다. 아래 매체·소속 인물 제외 조건은 해외 재게시와 본인 SNS에도 그대로 적용하며 사진 출처와 게시물 링크를 남긴다. 해외 출처라는 사실을 재사용 허락 확인으로 표시하지 않는다.
- 최신 사용자 우선순위: 연예인 본인 인스타그램의 공개 게시물에서 해당 근황의 사진을 먼저 확인하고 원본을 저장한다. 공식 계정 여부·게시 날짜·게시물 링크를 기록한다. 로그인 없이 보이는 목록 미리보기와 개별 게시물의 전체 이미지를 구분하며, 공개 SNS라는 이유만으로 재게시 권한이 확인됐다고 표시하지 않는다. 아래 매체·소속 인물 제외 기준은 본인 SNS 사진에도 유지한다.
- 뉴스1(News1), 디스패치(Dispatch), 매체 이름에 ‘조선’이 들어가는 모든 미디어의 사진은 사용하지 않는다. 조선일보·조선비즈·스포츠조선·TV조선 등도 포함한다. 다른 뉴스·블로그·포털에 재게시되어 있어도 원촬영자·사진 제공처·크레딧이 해당 출처이면 제외한다.
- 갤럭시코퍼레이션 소속 인물의 사진도 사용하지 않는다. 다른 소속사 인물과 함께 나온 단체 사진·콜라주도 해당 인물이 있으면 제외한다. 소속은 사진 선택 시 최신 공식 자료로 확인한다. [공식 회사소개](https://insights.galaxyuniverse.ai/faq/company/)에서 확인한 2026-10-06 목록은 지드래곤·태민·김종국·송강호·이정후·류준열·정일우다. 이 목록을 영구 고정하거나 전수 목록으로 단정하지 않는다.
- 위 제외 기준은 사진·본문 이미지·썸네일에 적용한다. 사실 확인용 기사 열람과 사진 재사용은 별개다. 탑을 지드래곤과 혼동해 제외하지 않는다.
- 사용자 제공 사진과 재사용 허용 범위가 확인된 공식 자료를 우선한다. 방송사·소속사·공식 SNS 사진도 공개됐다는 이유만으로 사용 허가가 있다고 표시하지 않는다. 권한 미확인 사진은 출처 확인 후보로 구분하며 완성본에 사용 가능 사진으로 넣지 않는다.
- 캡처와 다운로드 모두 같은 기준으로 고른다. 캡처·크롭으로 워터마크나 크레딧을 숨기지 않는다. 구독자 전용 버블 메시지·사진은 공개 홍보 이미지와 구분해 제외한다.
- 연예 원고의 이후 네이버 입력 대상은 `dangke-` 블로그다. 현재는 사용자 로그인 대기로 로컬 준비만 한다. 다른 계정의 기존 원고를 열거나 수정하지 않으며, 발행은 별도 요청 때만 한다.

열린 네이버 크리에이터 어드바이저의 2026년 10월 5일 스타·연예인 검색어 20개에서 각 검색 유입 게시물 1~10위, 총 200개 항목을 확인했다. 반복 등장 블로그 34개와 지정 블로그를 합쳐 36개 블로그의 대표 글 62편을 분석했다. 지정 표본은 임씨 2편, 찌롱 3편, 집구석 언니 4편이다. 나머지는 블로그별 1~2편이다. 블로그 전체 전수 분석은 아니다.

순위는 어드바이저의 해당 날짜 검색 유입 게시물 목록 순서다. 현재 검색 결과 순위나 실제 홈피드 노출 실적을 뜻하지 않는다. 같은 글이 유사 검색어에 여러 번 등장한 경우를 별도 글 성과로 세지 않는다. 반복 횟수, 서로 다른 검색어 수, 고유 게시물 수, 사건 묶음 수를 구분했다. 같은 검색어 안에서 두 글이 나온 경우도 전체 등장 횟수에는 포함한다.

글자 수는 본문 영역의 비어 있지 않은 텍스트 문단을 가져와 제로폭 문자를 제거하고, 앞뒤 공백을 정리한 뒤 한 줄바꿈으로 연결한 값이다. 본문 안의 소제목·표 텍스트·해시태그·출처 문구·직접 입력한 URL은 포함하며 제목 영역·광고·댓글·자동 링크카드 설명은 제외한다. 따라서 네이버 편집기의 글자 수와 정확히 일치하지 않을 수 있다. 공백 포함과 공백 제외를 함께 기록한다.

문단 수는 HTML 텍스트 문단 수다. 집구석 언니처럼 한 줄마다 문단을 만드는 글에서는 의미 단락 수보다 훨씬 커진다. 사진 수는 본문 사진 리소스 수이며 콜라주 내부 개별 사진, 스티커, 자동 링크카드와 구분한다. 볼드는 b/strong 요소 수로 단어 수나 강조 비율이 아니다. 일반 span의 굵기가 400이어도 내부 볼드가 있을 수 있어 따로 측정했다. 서식은 현재 데스크톱 페이지의 표시값이다.

분석 결과는 글의 구성에 관한 관찰이다. 글 안의 연예 소식, 건강·법률 설명, 시청률, 나이와 작품 정보는 새 원고 작성 시 공식 발표·방송·소속사 자료로 다시 확인한다. 타인의 경험과 문장·사진은 다예 원고로 옮기지 않는다.

본문 1,938~2,745자, 공백 제외 1,494~2,077자. 사진 6~12장, 볼드·스티커·표는 없다. 15px 나눔명조 계열 회색, 가운데 정렬을 중심으로 하고 19px 인용구에서 제목을 반복한다. 파란 글자는 이 표본에서는 주로 해시태그에 나타나므로 본문 핵심 색칠과 혼동하지 않는다. 장문 문단 사이에 사진을 넣고, 별도 소제목을 많이 만들지는 않는다.

다예 적용은 **인물 관계를 독자가 헷갈리지 않게 설명하는 순서**다. 관련 인물 이력은 현재 사건을 이해하는 데 필요한 만큼만 넣는다. 문단은 더 짧게 나누고, 감정은 사실 뒤 한 문장으로 덧붙인다. 건강 전망 등 제3자 글의 일반화는 근거 없이 재사용하지 않는다.

### 집구석 언니

[블로그](https://blog.naver.com/homenews_). [엘라 근황](https://blog.naver.com/homenews_/224433119399), [김고은 글](https://blog.naver.com/homenews_/224431990578), [이가윤 프로필](https://blog.naver.com/homenews_/224431808466), [이대범 프로필](https://blog.naver.com/homenews_/224431796716)을 비교했다.

홈피드 제목은 변화·사진 속 장면에 대한 궁금증으로 시작하고, 프로필 제목은 인물명에 나이·가족·방송·근황을 붙인다. 두 유형을 제목부터 다르게 쓴다. 본문은 최근 사진이나 방송 장면으로 열고, 기본 정보와 성장·활동 이야기를 풀어 쓴 뒤 개인적인 감상으로 마무리한다.

본문 1,029~1,952자, 공백 제외 798~1,496자. 사진 6~15장, 볼드 3~7개, 스티커와 표는 없다. 19px 어두운 본문과 가운데 정렬, 짧은 줄바꿈이 특징이다. 프로필 표본은 왼쪽 선 인용구를 소제목으로 사용하고 마지막 관련 글은 모서리형 인용구와 링크카드로 연결한다. 본문 색칠은 적고 사진과 여백이 구획을 만든다.

**프로필 작성법:** 이가윤 글은 최근 부녀 사진→나이·가족→배우 준비 과정→사진에 대한 반응→아버지 이력→앞으로의 활동 순서다. 이대범 글은 방송의 중심 사연→나이·이력→삶의 전환점→재활과 음악→아내·가족→현재 활동으로 이어진다. 단순 항목 나열보다 “지금 이 인물을 찾아보는 이유”를 프로필의 중심에 둔다.

다예에게 가장 가까운 부분은 해요체와 짧은 줄, 정보를 받은 뒤의 가벼운 반응이다. 다만 명사나 문장 중간을 지나치게 끊는 방식까지 복사하지 않는다. 가족 마음을 단정하거나 과거 방송 경험을 다예 경험처럼 쓰지 않는다. 이가윤은 활동 단계에 관한 설명이 있고, 김고은 글은 성장 환경과 국적의 의미를 구분하는 방식이 있다. 이런 구분은 새 글에서도 공식 근거를 확인해 유지한다.
