# 여행 블로그 2곳의 표본 비교와 원고 기준

분석일: 2026-10-06. 밍짱이 3개 글(투어·호텔·교통카드), 단디쓰 3개 글(숙소·맛집·축제)을 비교했다. 서로 다른 글 유형이므로 모든 차이를 작성자의 고정 성향으로 단정하지 않는다. 순위·조회수 효과를 검증한 자료는 아니다.

상세 근거: [밍짱이](blog-visual-audit/README.md), [단디쓰](dandi-blog-analysis/README.md). 구성 요소 목록과 측정값은 각 폴더에 있다.

볼드 비중은 공백·빈 문자·태그를 제외한 일반 텍스트 요소의 글자 기준이다. 인용구·가격표의 볼드는 비중 계산에서 제외했으며 별도 분석했다.

## 두 블로그에서 함께 관찰한 원리

1. 지역·장소·상품명과 독자가 확인하려는 정보를 제목에 모은다. 관심을 끄는 도입 표현의 강도는 다르다.
2. 여행자 상황이나 고민을 먼저 제시한다. 숙소는 동행 인원, 투어·교통은 일정과 사용 조건, 맛집은 방문 계기와 선택 이유를 활용한다.
3. 짧은 줄·빈 줄·사진을 번갈아 배치하고 소제목으로 탐색을 돕는다. 특정 글자 크기·색·목차가 공통인 것은 아니다.
4. 가격·시간·위치·인원·제한 등 결정에 필요한 정보를 준다. 표·정보 인용구·사진 중 주제에 맞는 형식을 선택한다.
5. 장점과 함께 주의사항·준비물·제외 조건을 설명한다. 실제 경험과 조사 정보·미확인 항목을 구분한다.
6. 결론에서 추천 대상과 이유를 정리하고 관련 링크·태그로 이어진다. 상품 전환과 관련 글 탐색이라는 링크의 목적은 다르다.

## 원고를 만들 때의 선택 기준

- 숙소·맛집 체험 후기: 다예가 제공한 실제 사진·경험을 중심으로 단디쓰 표본처럼 동선과 감각을 연결한다. 가격·예약·준비물은 따로 정리한다.
- 가격·쿠폰·교통·투어 비교: 밍짱이 표본처럼 목차·비교표·강조·제한 조건을 활용한다. 글 전체를 굵게 만드는 것은 필수 규칙이 아니다.
- 축제·행사 사전 안내: 단디쓰 축제 표본처럼 공식 일정·체험·공연·주차·추천 동선을 분리한다. 방문하지 않은 현장 경험을 만들지 않는다.
- 서식은 원고의 정보량과 다예 블로그 화면에 맞춘다. 편집 안내에는 소제목 양식, 볼드/색/밑줄, 사진·표·영상, 스티커 역할, 링크·태그 위치를 지정한다.
- 최신 가격·할인·운영시간·행사 일정은 새 원고를 작성할 때 다시 검증한다. 참고 블로그 문장을 가져오지 않고 다예의 자료를 바탕으로 새 문장을 쓴다.

추가 블로그를 분석하면 이 공통 원리를 보강하고 개인적인 편집 취향을 분리한다. 현재 자료는 두 작성자의 총 6개 글에 해당한다.
