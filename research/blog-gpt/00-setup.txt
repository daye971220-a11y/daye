이름: 블로그 원고와 사진 작가
설명: 주제와 자료로 자연스러운 한국어 블로그 원고를 쓰고, 문단에 맞는 스마트폰 기록사진과 이미지 프롬프트를 만드는 공용 도우미.

설정용 파일
01-GPT-instructions.txt: 지침 입력란에 내용 전체를 붙여 넣기.
02-blog-knowledge.txt, 03-photo-prompts.txt: 지식 파일로 첨부하기.
04-preview-checks.txt: 설정 후 미리보기에서 시험할 요청과 합격 기준.
이 안내와 열람 기록은 일반 사용자용 지식에 첨부하지 않아도 됩니다.

도구
작성 시점의 사실 확인을 위한 웹 검색과 실제 사진 제작을 위한 이미지 생성 기능이 제공되는 환경에서는 활성화합니다. 실제 제공되는 기능과 명칭은 계정·제품 화면에 따릅니다. 외부 서비스에 입력하거나 네이버 임시저장하는 액션은 필요 없습니다. 이미지 생성이 없는 환경에서는 완성 프롬프트를 전달합니다. 파일 첨부만으로 사진 생성 기능이 생기는 것은 아닙니다.

대화 시작 예시
1. 이 숙소 링크로 가족 여행자가 궁금해할 객실·수영장·조식을 중심으로 원고 써줘. 직접 가본 적은 없어.
2. 이 제품을 사용한 메모로 자연스러운 후기 써줘. 내가 적은 경험만 사용해줘.
3. 이 축제 공식 자료로 일정과 동선이 잘 보이는 블로그 원고 써줘.
4. 방금 원고의 조식 문단에 넣을 자연스러운 스마트폰 사진 한 장 만들어줘.

설정 후 확인
우선 비공개 미리보기에서 04-preview-checks.txt를 실행하고 출력과 사진을 실제로 확인합니다. 문제가 있으면 지침을 수정합니다. 공개 범위·배포는 계정 화면에서 원하는 범위로 설정합니다. 유료 강의 원문·전자책·타인 사진·개인 얼굴 사진을 공용 GPT에 추가하지 않습니다.

이번 작업의 완료 범위
등록에 사용할 지침·지식·사진 프롬프트 파일을 만들었습니다. 현재 연결된 브라우저의 GPT 편집 URL에서는 입력 가능한 편집 화면을 확인하지 못해 계정 안의 GPT 생성·저장·공개 및 실제 미리보기 실행은 완료하지 못했습니다. 등록 완료나 성능 검증 완료로 표시하지 않습니다.
계정에 GPT 생성 화면이 제공되면 위 파일을 이용합니다. 생성 화면이 제공되지 않는 경우에는 일반 대화에 01의 지침과 02·03을 첨부해 동일한 작성 기준을 사용할 수 있습니다. 제품의 GPT·플러그인 전환 안내는 https://learn.chatgpt.com/docs/migrate-custom-gpts 를 참고합니다. 자동으로 플러그인을 설치하거나 GPT를 대체하지 않았습니다.
