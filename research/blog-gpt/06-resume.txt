공용 블로그 GPT 이어서 작업 — 2026-10-12

사용자 요청
SNS 노션 자료와 기존 작성 지침을 합쳐 누구나 쓰는 블로그 GPT를 만든다. 원고와 사진 생성·프롬프트가 목적이며 네이버 편집·임시저장·발행 기능은 제외한다. 특정 사용자의 이름·계정·얼굴·개인 경험은 기본 설정에 넣지 않는다. 로그인으로 막힌 Claude SNS 노트 227개는 사용자 요청으로 제외했다.

현재 결과물은 모두 이 폴더에 있다.
00-setup.txt: 이름·설명·등록 방법·대화 시작 예시.
01-GPT-instructions.txt: GPT 지침란에 전체 붙여 넣을 실행 지침.
02-blog-knowledge.txt: 장르별 작성·검수 지식. 지식 파일로 업로드.
03-photo-prompts.txt: 사진 질감·촬영 시점·배치·생성 검수. 지식 파일로 업로드.
04-preview-checks.txt: 등록 후 실제 실행할 검수 요청 8개.
05-reading-audit.txt: 열람 범위·접근 제한·관련 페이지 186개 확인 목록. 공용 GPT에 업로드할 필요 없음.
06-resume.txt: 이 진행 기록. 공용 GPT에 업로드할 필요 없음.

완료한 것
공용 설정 파일 5개를 만들고 이름·계정·개인 얼굴 정보가 없는지 확인했다. 여행·숙소·축제·제품·경제·대학·연예·공연/전시 작성 기준과 자연스러운 스마트폰 사진 프롬프트를 반영했다. 여행 전체 사진은 서로 다른 본문 장면 11장 이상과 별도 글씨 없는 썸네일을 기본 계획으로 하며, 한 장 요청에는 한 장을 만든다. 직접 경험을 만들지 않으며 최신 가격·쿠폰·일정·정책은 작성 시점에 다시 확인한다. 유료 자료 원문·타인 원고·참조 사진은 이 폴더에 포함하지 않았다.

아직 하지 못한 것
연결된 브라우저의 GPT 편집 URL에서 입력 가능한 화면을 확인하지 못했다. 실제 계정의 GPT 등록·저장·공개 및 미리보기 8개 실행은 미완료다. 사진 생성 결과를 실제 미리보기에서 검수하지 않았으므로 일정 품질이 바로 보장된다고 주장하지 않는다. 접근 제한 자료·자막 미확보 영상·모든 엑셀 수치 셀까지 전부 읽었다고 주장하지 않는다. 자세한 범위는 05를 읽는다.

회사에서 다음에 할 일
1. 저장소에서 git pull을 실행하고 이 폴더와 AGENTS.md의 공용 GPT 기록을 읽는다.
2. 사용자의 계정에 제공되는 GPT 생성·편집 화면을 확인한다. 화면이 있으면 00 안내대로 01 지침과 02·03 지식을 입력하고 제공되는 웹 검색·이미지 생성 기능을 활성화한다.
3. 비공개 미리보기에서 04의 요청을 실제 실행하고 제목·사실·경험·사진 촬영 시점·문맥을 확인해 필요한 부분을 수정한다.
4. 등록·실행 상태를 정확히 기록한다. 공개 범위는 사용자의 요청과 계정 화면에 따라 정한다.
5. 수정한 지침 파일과 진행 기록만 명시하여 커밋·푸시한다. 다른 원고의 미커밋 변경을 함께 올리지 않는다.

주의
대화 기록과 delivery 폴더는 컴퓨터 간 Git 동기화 대상이 아니다. 회사에서는 이 research/blog-gpt 폴더를 기준으로 이어간다. 기존 쇼핑 원고 30편 등 별도 작업의 변경은 이번 저장 범위에 포함하지 않는다. 강의 원문·다운로드·OCR 임시 파일을 옮기지 않으며 다시 필요한 원자료는 원본 링크로 접근한다.
