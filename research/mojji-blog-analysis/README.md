## 제목과 도입

제목은 지역·장소·상품명 뒤에 검색자가 확인할 정보를 길게 모은다. 숙소는 객실·수영장·조식·식당·부대시설을, 크루즈는 후기·가격·승선 위치·실외석을 넣는다. 두 숙소 제목은 총정리로 끝나고 크루즈는 구체적인 선택 항목으로 끝난다.

도입은 여행 시기/동행 → 선택 고민 → 추천 결론 → 이번 글에서 얻을 정보의 순서다. 숙소는 11월 여행 준비·아이 동반에 연결하고 크루즈는 작년 12월 부모님과 다녀온 경험을 밝힌다. 인사말을 길게 쓰지 않는다. 첫 사진과 다음 사진 사이에 선택 이유를 나누어 적고 예약 링크 카드로 넘어간다.

## 문장과 말투

짧은 구어체 존댓말에 ㅎㅎ·ㅋㅋ·:)·:-)·>_<·ㅎ_ㅎ 같은 문자 이모티콘을 섞는다. 컬러 이모지와 문자 이모티콘은 다른 집계다. 단정적인 추천, 독자에게 말을 거는 질문, 자신이라면 고르겠다는 조건부 추천이 함께 나온다. 시설 설명 뒤에 아이·부모님·커플에게 어떤 편의가 생기는지 붙인다.

직접 줄을 나눈 일반 본문 문단의 공백 제외 글자 수 중앙값은 16·16·16.5자다. 문장 전체 길이나 모바일 자동 줄바꿈 수와 다르다. 모든 구성 요소에서 빈 문단은 65·65·69개이며 사진 앞뒤와 이야기 전환에 여백을 만든다.

## 스티커와 이모지

세 편 모두 첫 요소는 흰 캐릭터 두 마리와 수수료 제공 사실을 알리는 고지 스티커다. 직접 비용을 지불했다는 경험 서술과 파트너스 고지가 함께 존재할 수 있다. 크루즈는 첫 도입에서 내돈내산 방문을 말하면서 첫 스티커로 현재 링크의 수수료를 고지한다.

두 번째 스티커는 아래 화살표를 든 같은 계열 캐릭터와 링크 참고 안내다. 도입 마지막과 첫 예약 카드 사이에 둔다. 뉴월드에만 결론 직전 큰 분홍 하트를 든 캐릭터가 추가된다. 각 스티커의 이미지 URL·위치·표시 크기는 측정 파일에 남겼다.

## 본문 순서와 사진 역할

세 편 모두 9개 소제목이며 번호 목차는 없다. 가격을 첫 소제목에 두어 예약 판단을 일찍 돕는다. 그 뒤 위치와 접근 → 객실/배 내부 → 음식/수영장 → 이용 팁 → 총평으로 흐른다.

쏠비치: 가격 → 위치 → 디럭스 오션뷰 → 인피니티풀 → 사우나/피트니스 → 조식 → 식당/카페 → 주변 여행지 → 총평.

뉴월드: 가격 → 위치/공항 셔틀 → 가든 풀빌라 → 수영장/워터파크 → 조식 → 식당/비치바 → 마사지/스파 → 해변 산책 → 총평.

크루즈: 가격 → 아이콘시암 승선 → 배 내부 → 뷔페 → 실외석 → 야경 → 공연/드론쇼 → 복장/아이 동반 → 총평.

사진을 몇 장씩 몰아서 설명하기보다 짧은 설명과 한 장을 번갈아 놓는다. 같은 시설·음식·풍경의 보완 사진은 2장 나란히 배치한다. 크루즈에서는 음식과 야경을 보여주고 그 뒤 이용 팁·경험을 연결한다. 가격 설명도 표 대신 문장과 사진으로 전개한다. 단일 사진의 폭은 이미지마다 다르고 세로 사진도 섞이므로 하나의 고정 크기로 단정하지 않는다.

## 숙소 가격 비교에서 참고할 점

쏠비치는 11월 12일 목요일 1박 2인이라는 조건을 먼저 제시한다. 객실 288,000원, 케이블카 2인+음료 2잔 332,000원, 인피니티풀 2인 336,000원, 조식 2인 396,000원을 소개한다. 객실만 대비 차액은 각각 44,000·48,000·108,000원이다. 이는 글의 소개 가격끼리 계산한 것이며 현재 예약가나 개별 구매 대비 절약액을 검증한 결과는 아니다. 객실 기준 인원과 패키지 혜택 대상 2인은 별도로 표시해야 한다.

뉴월드는 같은 날짜의 1박 2인 가든 풀빌라 조식 포함 671,596원, 세금·봉사료 포함이라고 설명한다. 다른 침실 수 빌라와 두 가족 여행을 추천하지만 서로 다른 객실을 동일 조건 비교로 합치면 안 된다. 조식 포함/불포함 7천 원 차이도 해당 상품·날짜·인원의 대응 근거를 실제 사이트에서 확인한 뒤 활용한다.

크루즈는 10월 기준 성인 1인 54,000원, 좌석 옵션별 같은 가격을 설명한다. 가격 시점이 방문 시점(작년 12월)과 다르다. 당일 예약·무료 유아 나이·체크인/출항·좌석 확정 조건은 실제 상품에서 다시 확인해야 한다. 출항 18:45와 하선 21시 무렵을 함께 서술하므로 소요 시간 2시간 표현은 현 상품 운항 시간과 대조한다.

## 예약 링크의 설계

예약 카드 1개를 도입 뒤에 두고 설명 절마다 다른 문구로 링크를 반복한다. 쏠비치·뉴월드의 위치/객실/수영장/조식 링크는 대부분 각 숙소의 같은 여기어때 주소다. 크루즈의 시간/후기/포함 내역/좌석/운항 코스 링크도 같은 마이리얼트립 상품 주소다. 문구가 다르다고 별도 상세 페이지가 있는 것은 아니다.

가격 소개 → 상품 확인 → 할인쿠폰 받기 → 시설 설명 → 해당 항목 확인 → 결론의 날짜별 비교/예약 순으로 이어진다. 새 원고에서는 링크가 실제로 보여주는 정보와 안내 문구를 맞추고, 다예님이 제공한 예약 주소를 사용한다. 분석 대상의 파트너스 주소를 복사하지 않는다.

## 경험·사진 출처의 구분

쏠비치 마지막은 여기어때와 쏠비치 남해, 뉴월드는 여기어때와 뉴 월드 푸꾸옥 리조트라고 사진 출처를 명시한다. 외부 실제 사진을 활용하는 사례로 참고하되 사진 크레딧만으로 촬영자나 재사용 권한이 확정되지는 않는다. 두 숙소 글의 일반적인 시설 묘사만 보고 직접 숙박했다고 단정하지 않는다.

크루즈는 부모님 동행, 실외석 가장자리, 입은 옷, 식사 반응, 탔던 날의 드론쇼를 구체적으로 서술한다. 촬영 저작권은 텍스트만으로 확정하지 않는다. 특히 당일 드론쇼는 모든 운항의 기본 포함 공연으로 바꾸면 안 된다.

다예님 원고는 제공한 경험만 1인칭 후기로 쓰고, 조사한 시설·다른 후기·개인적인 추천을 구분한다. 숙소 사진은 실제 객실명·전망·시설·출처를 연결해 추천하고, 생성 이미지를 실제 객실 사진으로 표시하지 않는다.

## 태그와 앞으로 적용할 기준

본문 안 손글씨 태그 문단은 세 편 모두 없다. 네이버 등록 태그는 쏠비치 3개, 뉴월드 3개, 크루즈 4개다. 플랫폼 태그 UI와 본문 서식을 구분한다.

모찌트립에서 적용할 것은 가격 조건을 먼저 밝히는 구성, 시설 장점과 동행 유형 연결, 실제 경험의 작은 디테일, 절별 사진과 관련 링크, 사진 출처다. 다예님 원고에는 예약 사이트별 같은 날짜·객실·인원·세금·조식·취소 조건을 맞춘 비교표와 확인 시점을 더해 선택을 돕는다. 링크 반복 횟수·색·스티커 수는 관찰값이며 검색 상위 노출 공식으로 취급하지 않는다.
