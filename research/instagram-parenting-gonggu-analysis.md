# 육아 공구 인스타그램 계정 분석과 이어하기

다예는 좋은 육아용품을 합리적인 가격에 살 수 있다는 기대 때문에 팔로우하는 인스타그램 계정을 키우려 한다. 참고 계정은 [희아 패밀리](https://www.instagram.com/heeah_family/)와 [켈리맘](https://www.instagram.com/kelley_mom_dad/)이다. 두 계정의 예고부터 오픈·마감까지 게시 일정, 릴스·카드뉴스 구성, 캡션, 스토리, 혜택과 구매 설득 방식을 비교했다.

확인일은 **2026년 10월 12일 한국 시간**이다. 각 계정의 공개 게시물 24편씩, 총 48편의 본문과 게시 시각을 직접 읽었다. 희아는 가격·구성·친근한 추천을, 켈리맘은 사용 경험·선택 기준·반복 예고를 두드러지게 활용한다. 공통적으로 제품을 고르는 일과 구매 조건을 비교하는 부담을 덜어주는 방식이다. 이는 콘텐츠에 대한 마케팅 해석이며 실제 구매 전환율을 측정한 결과는 아니다.

## 집에서 이어가기

1. 이 프로젝트에서 `git pull --ff-only`로 최신 문서를 받는다. 로컬 변경 때문에 실패하면 강제로 덮어쓰지 않는다.
2. `AGENTS.md`의 최신 이어하기 항목과 이 문서를 읽는다. 대화 원문이나 브라우저 로그인 상태가 다른 컴퓨터에서도 남아 있다고 가정하지 않는다.
3. 사용자가 단순히 이어달라고 하면, 이 분석을 바탕으로 **추가 계정 분석을 할지, 다예 계정의 운영안을 만들지** 먼저 짧게 확인한다. 계정 콘셉트와 공구 상품은 아직 확정하지 않았다.
4. 운영안으로 넘어갈 경우 다예의 계정 유무, 주요 독자의 아이 월령, 실제 사용해본 상품, 첫 공구 후보를 확인한다. 이를 사용자가 이미 제공한 것처럼 만들지 않는다.
5. 실제 첫 상품이 정해지면 예고·사용 장면·선택 안내·OPEN·마감의 역할을 나눈 일정과 콘텐츠를 설계한다. 아래 관측 횟수를 모든 상품의 고정 정답으로 적용하지 않는다.

집에서 사용할 요청 예시: “육아 공구 인스타 분석 이어서 해줘. research/instagram-parenting-gonggu-analysis.md부터 읽어줘.”

**완료한 일:** 48편의 본문·게시 시각 분석, 일부 카드뉴스 장별 시각 확인, 일부 릴스 화면 확인, 희아 일정 하이라이트 일부 확인, 분석 결과 전달.

## 희아 패밀리의 글과 구매 설득

대표 흐름은 **가격·대상·상품을 담은 첫 문장 → 댓글 알림 → 오픈 일정 → 혜택 → 추천 품목 → 사용 상황 → 구매 권유**다.

락앤락 예고는 이유식 준비와 2만원대라는 가격을 앞에 둔다. 댓글로 가격대와 알림을 받게 하고, 여러 품목에 별표를 붙여 추천 강도를 표시한다. 이유식용기·밥용기·푸드자·초퍼 조합을 제안하며, 초퍼는 아기가 자는 밤에 믹서 소음이 부담되는 상황과 연결한다. 기능을 생활 속 불편과 연결하고 구매할 품목을 좁혀준다.

자브백은 제품별 장단점을 나누고, 물건이 아래에 깔리면 찾기 불편하다는 단점도 쓴다. 허그파파는 아이가 무거워지면서 생기는 허리 부담, 혼자 착용하는 상황, 가족이 함께 조절해 쓰는 상황을 제시한다. 이 설명은 사용자의 선택을 돕는 신뢰 장치로 해석할 수 있다.

세이펜은 공구가가 같다는 전제에서 사은품을 차별점으로 제시하고 신형 대신 기존 모델을 고른 이유를 설명한다. 프레벨롱은 8팩·20팩 구매 시 증정 차이를 보여주고, 떠먹기·짜먹기의 사용 시기를 나눠 설명한다. 낮은 가격대 제시, 선택 지원, 더 큰 구성 제안이 함께 작동한다.

## 켈리맘의 글과 구매 설득

대표 흐름은 **상품·오픈일·알림 방법 → 이벤트 → 생활 속 고민이나 경험 → 선택 이유 → 옵션·혜택 → 배송·문의 안내**다. 상품별 예외가 있어 고정 템플릿으로 강제하지 않는다.

소창수건은 조리원 근무 경험을 소개하고 수건이 필요한 구체적인 상황, 기존 제품의 불편, 다른 제품과의 가격·사용감 비교를 연결한다. 릴스 첫 화면에는 수건을 버리는 장면과 되돌아가면 특정 제품을 사지 않겠다는 문구를 사용해 궁금증을 만든다. 이후 선택 이유를 캡션에서 설명한다. 영상 일부 화면을 확인했으며 전편 음성을 전사하거나 모든 컷을 분석하지는 않았다.

가습기는 여러 제품을 바꿔본 경험과 장기 사용 설명 뒤에 안전장치·세척·용량·소음·AS 등 13개 체크리스트를 넣는다. 제품 안전성에 대한 독립 검증이 아니라 구매 비교 부담을 덜어주는 콘텐츠 구조로 참고한다.

호주어그의 4편은 날씨와 매장 방문 → 정가로 샀던 경험 → 인기 라인업·배송 시점 → 사이즈·배송 안내로 강조점을 바꾼다. 반복 노출 속에서 관심을 끌고, 필요성을 납득시키고, 실제 옵션을 고르게 하는 방식이다.

레드루트는 세트로 사면 유연제만 남는다는 불편을 짚고 세제 5개·유연제 2개 조합을 제시한다. 코코지는 아이의 사용 단계에 따른 조합을 나눠 소개한다. 단독 구성이라는 말에 그 구성이 필요한 이유를 붙이는 사례다.

두 계정에서 예고 확인 → 댓글로 알림 신청 → DM 또는 알림방에서 링크 확인 → 구매 → 구매 인증 참여의 안내가 반복된다. DM이 실제로 발송되는지, 자동화 도구가 무엇인지, 실제 구매 전환이 어느 정도인지는 시험하지 않았다. 희아 월간 일정 게시물에는 자동 DM이 걸려 있지 않으니 프로필의 알림방을 이용하라는 안내도 있다.

## 스토리 확인 범위

희아 [오픈일정 하이라이트](https://www.instagram.com/stories/highlights/18055355993764144/)에서 아이 착용·제품 사진을 묶고 날짜와 가격대를 붙인 리뗀클로르 안내 화면을 직접 보았다. 이후 추가 열람은 로그인 안내로 제한됐다. 희아 피드에는 재입고·추가 오픈을 스토리로 공지한다는 설명이 있다.

켈리맘 현재 스토리를 열었으나 로그인 안내가 나와 본문은 읽지 못했다. 피드에서는 공구 변동사항 공지와 스토리 공유 이벤트를 확인했다. 두 계정의 하루 또는 공구별 스토리 총수는 확인하지 못했다. 현재 남은 하이라이트 수를 과거 발행 개수로 환산하지 않는다.

팔로워에게 스토리 공유를 요청하는 것은 팔로워가 올리는 스토리를 늘리는 장치다. 운영자가 직접 하루 몇 장을 올렸다는 증거가 아니다. 정확한 전체 발행량 분석에는 접근 가능한 기록과 공구 전후 기간의 관측이 필요하다. 이 작업을 자동으로 예약하거나 모니터링하지는 않았다.
