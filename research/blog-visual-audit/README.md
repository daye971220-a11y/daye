## 3. 볼드·밑줄·형광펜의 조합

- 굵게 처리한 글자 비중은 일반 텍스트 요소에서 투어 약 51.4%, 호텔 63.2%, 교통카드 56.7%다. 빈 부분과 해시태그를 제외한 측정이며 글 전체 요소의 비율은 아니다. 짧은 문장 가운데 중요한 구절을 상당히 자주 굵게 쓴다.
- 검정 볼드는 옵션명, 가격, 혜택, 제한, 일정 선택 기준에 사용한다. 노란 형광펜은 볼드와 겹쳐 핵심 결론을 한 단계 더 강조한다.
- 직접 넣은 밑줄은 투어 17개, 호텔 30개, 교통카드 0개 구간이다. 링크의 밑줄은 각각 6개·6개·5개로 따로 셌다. 밑줄은 보통 굵은 글씨와 결합하지만 모든 볼드에 적용하지 않는다.
- 큰 파란 링크는 투어에서 19px 보통 굵기 2곳, 호텔에서 19px 굵게 1곳이 확인된다. 나머지 링크는 주로 16px다.
- 기울임과 취소선은 세 표본의 편집 본문에서 관찰되지 않았다.
- 소제목은 큰 볼드 제목이 아니라 명조체 인용구 장식이다. 소제목만 굵게 키우면 이번 표본과 다른 인상이 된다.

## 6. 목차·가격표·링크·지도

투어와 호텔은 1열 6행의 약 558px 목차 표를 가운데 둔다. 첫 행은 색 있는 제목 칸, 아래 5행은 본문 절이다. 교통카드는 오른쪽 아래가 접힌 종이 모양의 인용구 목차를 사용한다.

가격표는 세 글 모두 약 886px 폭, 가운데 정렬, 셀 여백 10px, 1px 회색 격자를 사용한다. 투어는 8행·논리적 3열, 호텔은 6행·3열, 교통카드는 7행·4열이다. 합쳐진 셀이 있어 보이는 칸 수와 논리적 열 수는 다르다. 투어·호텔은 제목과 조건 행을 합치고, 교통카드는 마지막 조건 행을 4열 병합한다. 가격만 넣지 않고 인원·옵션·포함·조건을 함께 설명한다.

각 글에는 이미지가 큰 링크 카드 2개와 지도 1개가 있다. 링크 카드는 도입 뒤와 결론 뒤에 반복되며 썸네일은 약 450×270px다. 카드에 자동으로 나타나는 회색 설명·초록 도메인 표시를 작성자의 수동 글씨 색으로 혼동하지 않는다.

## 7. 사진과 시각적 리듬

사진은 가운데 배치하고 설명 문단과 번갈아 넣는다. 표시 폭은 사진에 따라 달라 일률적으로 고정되지 않는다. 요소 설정에서 별도 테두리·모서리 둥글림·필터·투명도 효과는 관찰되지 않았다. 이것은 원본 사진 자체의 편집 여부를 뜻하지 않는다.

사진 역할은 장소 분위기, 시설·옵션 설명, 동선·사용법, 선택 결과의 예시다. 가격 설명·주의사항까지 사진으로 끊어 읽게 한다. 사진 없이 정보가 계속 이어지는 구간에는 표·이모지·스티커·인용구가 구분 역할을 한다. 독립적인 동영상·오디오·구분선 구성 요소는 세 표본에서 확인되지 않았다. 소제목 아래 선은 인용구 양식의 일부다.

## 8. 마지막 부분의 반복 구조

## 9. 다예의 원고에 적용할 편집 기준

1. 제목에는 지역·상품명과 독자의 질문 2~3개를 모은다. 제목 색은 다예 블로그의 실제 테마에 맞춘다.
2. 기본 본문은 16px 회색, 짧은 줄과 가운데 정렬을 출발점으로 삼는다. 기기별 가독성을 보고 조절한다.
3. 중요한 조건은 검정 볼드, 결정적인 한두 구절은 노란 형광펜, 할인·비용 조건은 필요한 부분만 빨강으로 표시한다. 시설 구분에 연두를 추가하는 방식은 호텔 표본의 선택 사항이다.
4. 직접 밑줄은 핵심 조건에 선택적으로 쓰고, 클릭 가능한 파란 링크와 구분한다.
5. 소제목 4~5개, 비교표, 설명에 대응하는 사진 자리를 제안한다. 스티커는 도입 마무리·중간 팁·끝 링크 앞처럼 역할이 있는 위치에 둔다.
6. 이모지는 항목 의미와 맞는 것을 사용한다. 모든 문장 끝에 붙이거나 표본의 횟수를 기계적으로 맞추지 않는다.
7. 실제 제휴가 있다면 해당 조건에 맞는 고지를 넣는다. 표본의 문구·캐릭터·경험담을 그대로 복제하지 않는다.
8. 원고를 요청받으면 새 문장으로 작성하고, 별도 편집 안내에 `[검정 볼드]`, `[노란 형광펜]`, `[밑줄]`, `[사진 위치]`, `[스티커 역할]`을 지정한다. 네이버 편집기에 붙여 넣은 뒤의 서식 적용까지 확인해야 화면과 같은 표현이 완성된다.

이 파일은 앞으로 이 대화와 저장된 자료를 참고해 원고를 작성하기 위한 기준이다. 모델 자체가 재학습되거나 다른 대화에 자동으로 기억된다는 의미는 아니다. 여러 블로그의 공통 규칙을 만들려면 다른 작성자의 표본을 추가해야 한다.
