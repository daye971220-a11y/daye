# 경제·생활 원고 7편 회사 이어보기 — 2026-10-08

사용자가 이번 7편과 사진·썸네일·분석 자료를 회사에서도 볼 수 있도록 daye GitHub에 저장하라고 명시적으로 요청했다. 이번 묶음에 한해 `delivery/economy-transfer.zip`을 Git에 보관한다. 다른 원고의 자동 보관 허가는 아니다.

## 회사에서 열기

1. daye 프로젝트에서 `git pull`을 실행한다.
2. `delivery/economy-transfer.zip`을 로컬 폴더에 압축 해제한다.
3. 압축을 푼 폴더의 `index.html`을 브라우저로 연다. 인터넷 없이도 사진과 서식을 확인할 수 있다.
4. `analysis.html`은 참고 32편의 제목·글자수·문체·서식·사진·구성 분석과 검색·출처, `all-copy.txt`는 복사 원고, `images.html`은 사진·별도 썸네일·후킹, `guide.html`은 편집 안내다.

## 완료 범위

경제·대학교 기준 파일과 참고 블로그 8개 각 4편 총 32편, 사용자가 열어둔 주제 글 7편, 추가 검색 글 14편을 읽고 공식 자료를 대조했다. 추가 글은 검색 화면에서 확인한 후보이며 정확한 검색 순위 1·2위나 검색량으로 단정하지 않는다. 이번에는 크리에이터 어드바이저를 열람하지 않았다.

원고 7편: 인간관계 금기 질문 / 5060 카페 매너 / MZ 취업·청년 쉬었음 / 밥값 계산·더치페이 / 50대 순자산 중위값·노후준비 / 공기업 취업 대학 비교 / JEPQ 3억 월배당.

본문 사진 35장과 별도 썸네일 배경 7장은 AI 제작 예시 이미지다. 자체 스티커와 글꼴·라이선스도 포함했다. 실제 방문·투자·취업 경험으로 표현하지 않는다. 확인되지 않은 유명인 발언·90%·대학 TOP3 주장은 제외했다. 통계 대상·연도, 중위값과 평균, 과거 분배율과 미래 보장액을 구분했다.

네이버에는 입력·임시저장·발행하지 않았다. 당시 다른 네이버 계정으로 로그인되어 있어 사용자가 검토본만 요청했다. 후속 작업은 기존 검토본을 수정하고 새 묶음을 중복 생성하지 않는다. 네이버 작업은 대상 블로그와 로그인 상태를 확인하고 사용자의 요청 범위에서만 진행하며 발행은 별도 요청 때만 한다. 새로운 작성일에는 수치와 출처를 다시 확인한다.
