# 텍사스파파 광고 운영 — 대표님과 정할 것 / 내가 알아야 할 것

(2026-10-08 정리. 대표님 = 외주를 맡긴 텍사스파파 쪽 대표님)

## A. 대표님께 물어볼 것

### 1. 범위
- [ ] 포스터 교체만인지, 광고 운영까지인지
- [ ] 운영이라면: 메타(인스타·페북)만? 네이버 검색광고도?
- [ ] 텍사스파파 공식 블로그 운영도 포함인지 (포함이면 별도 비용)
- [ ] 관리비에 포함되는 새 포스터는 한 달에 몇 장까지인지
- [ ] 창업 문의 응대·상담·계약은 본사가 하는지 (나는 광고까지만)
- [ ] 광고 문구·포스터 최종 승인은 누가 하는지

### 2. 현재 광고 상태
- [ ] 지금 메타 광고를 어떻게 하고 있는지 (직접 / 다른 대행사)
- [ ] 한 달 광고비는 얼마인지
- [ ] 한 달 창업 문의는 몇 건인지 (→ 문의 1건당 비용 계산, 바꾼 뒤 비교 기준)
- [ ] 문의는 어디로 받는지 (인스타 DM / 리드 양식 / 전화 / 홈페이지)
- [ ] 지금까지 계약까지 간 건 몇 건인지
- [ ] 네이버 광고 계정이 있는지 (없으면 새로 개설)

### 3. 계정·권한
- [ ] 메타: 비즈니스 관리자에서 내 계정 "사람 추가" (비밀번호 공유 X)
- [ ] 네이버: 텍사스파파 사업자 명의로 개설 → 광고주센터 설정 > 권한 관리 > 멤버 초대로 내 네이버 ID 추가
- [ ] 권한 수준: 조회만 / 광고 관리까지
- [ ] 광고비 결제(카드, 네이버 비즈머니 충전)는 대표님이 직접

### 4. 광고 예산 (대표님 돈)
- [ ] 메타 월 예산
- [ ] 네이버 월 예산 (제안: 크레페 관련 키워드만 월 20~30만 원 + 부가세로 한 달 테스트)
- [ ] 예산 늘리기·줄이기는 대표님 승인 후

### 5. 내 보수
- [ ] 월 관리비: 20만 원 / 30만 원 확정 (예: 테스트 첫 달 20, 이후 30)
- [ ] 관리비와 광고비는 별개 확인
- [ ] 지급일, 방식 (계좌이체 / 3.3% 원천징수)
- [ ] 계약 성과금 100만 원
  - 내 소개로 인정하는 방법 (문의 시 "다예 블로그 보고 옴", 전용 링크·문의 양식 칸)
  - 언제 지급 (가맹 계약일 / 가맹비 입금 후)
  - 메타·네이버 광고로 들어온 문의도 성과금 대상인지, 블로그·카페 소개만인지

### 6. 진행 방식
- [ ] 시작일
- [ ] 첫 달 = 테스트 기간 (바로 성과가 안 날 수 있음)
- [ ] 보고: 매주 ○요일 카톡 (광고비 / 문의 수 / 문의당 비용 / 잘 된 포스터)
- [ ] 연락 가능 시간: 평일 낮은 회사라 저녁·주말 확인
- [ ] 그만둘 때: 한 달 전 미리 말하기

### 7. 광고 내용 확인 (법)
- [ ] 월매출 5,000만 원, 순수익률 47%, 원가율 20%, 폐업 0건 → 본사가 근거 자료 가지고 있는지
- [ ] "국내 1위" 표현 → 근거 없으면 빼기 ("국내 최초 크레페 프랜차이즈"는 공식 표현)
- [ ] 광고 문구 책임은 본사 최종 승인

## B. 내가 알아야 할 것

### 용어 4개
| 용어 | 뜻 |
|---|---|
| CPC | 클릭 1번당 비용 (네이버 검색광고의 가격 단위) |
| CPL | 문의 1건당 비용 ← 제일 중요 |
| CTR | 광고 본 사람 중 클릭한 비율 (포스터가 끌리는지) |
| 빈도 | 같은 사람이 광고를 몇 번 봤는지 (3~4 넘으면 포스터 교체) |

### 메타 (인스타·페북)
- 구조 3단: 캠페인(목표: 잠재고객) → 광고 세트(누구에게·얼마·어디에) → 광고(포스터·문구)
- 리드 양식: 이름·연락처·희망 지역·창업 시기·예산 묻기
- 키워드가 없음 → 포스터가 곧 타겟 (퇴사 직장인 편, 가족 창업 편, 업종 변경 편이 각각 다른 사람에게 닿음)
- 시안 3~5개 같이 돌리고 일주일 뒤 문의당 비용 낮은 것만 남기기
- 켜고 3~7일은 학습 기간, 매일 건드리지 않기
- 같은 포스터 2~3주 지나면 반응 떨어짐 → 변형 시안 추가

### 네이버 검색광고 (파워링크)
- 검색창 단어(키워드)를 사서 검색 결과 위에 [광고] 글자 링크 띄우기. 포스터 안 씀
- 클릭할 때만 돈 나감, 비즈머니 미리 충전, 하루 예산 상한 걸 수 있음
- 제외 키워드 꼭 걸기: 무료, 알바, 채용, 레시피, 만들기, 부업
- 광고 문구는 키워드를 받아쓰기: "크레페 창업, 1,450만 원부터 · 원가율 20%"

### 키워드 데이터 (2026-10-07 네이버 키워드 도구 직접 조회, 월 검색량 PC+모바일)
| 키워드 | 월 검색 | 클릭당 (모바일 1위~5위) |
|---|---|---|
| 텍사스파파창업 | 10 미만 | - |
| 크레페창업 | 140 | 1,640~70원 |
| 크레페프랜차이즈 | 50 | 1,680~70원 |
| 디저트창업 | 110 | 15,320~11,210원 |
| 디저트카페창업 | 210 | 21,610~14,260원 |
| 소자본카페창업 | 110 | 17,430~9,340원 |
| 카페창업비용 | 2,050 | 17,340~13,830원 |
| 1인창업 | 1,040 | 26,660~22,830원 |
| 카페창업 | 3,240 | 23,320~17,670원 |
| 여자창업 | 1,460 | 20,620~18,160원 |
| 소자본창업 | 4,970 | 30,680~28,300원 |
- 텍사스파파 창업은 아직 검색이 거의 없음 → 메타로 먼저 알리는 게 주력
- 사람들은 "OO창업"보다 "OO창업비용"을 더 많이 검색 (메가커피창업 2,840 vs 메가커피창업비용 5,800) → 비용을 앞세운 광고가 유리
- 예상 월 비용: 크레페·디저트 키워드만 20~30만 원 / 카페창업비용·1인창업 추가 시 약 130만 원 / 소자본창업 등 큰 단어까지 650만 원 이상 (부가세 별도, 네이버 평균 입찰가 추정치)

### 블로그
- 계약 성과금(100만 원)용 소개는 내 블로그로. 대가를 받으니 "광고/협찬" 표시 필수 (안 하면 뒷광고)
- 글에서 수익·계약 조건 약속 X → "자세한 건 본사 상담"으로 연결만
- 텍사스파파 공식 블로그 운영은 별개 일 → 하게 되면 범위·비용 따로

### 내 쪽에서 미리 정할 것
- 최소 조건 (관리비 얼마 미만이면 포스터만 할지)
- 못 하는 것: 문의 전화 응대, 평일 낮 즉시 대응
- 다니는 회사의 겸업 규정 확인

## C. 정해지면 카톡으로 남기기

> - 관리비: 월 ○○만 원, 매달 ○일 지급

> - 광고비: 메타 월 ○○만 원 / 네이버 월 ○○만 원 (대표님 결제)
> - 계정: 메타 사람 추가, 네이버는 텍사스파파 명의 개설 후 저 초대
> - 시작: ○월 ○일, 첫 달은 테스트
