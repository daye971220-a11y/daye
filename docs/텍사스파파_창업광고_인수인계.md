## 집(다른 컴퓨터)에서 이어서 하는 법
1. `git pull` 로 이 문서 받기
2. Claude 새 대화에서 이렇게 말하기:
   > `docs/텍사스파파_창업광고_인수인계.md` 보고 텍사스파파 광고 시안 이어서 해줘. 캔버스: https://claude.ai/artifact/D3qSA62Zbmh7AY1MKSbAgi
3. Claude는 캔버스를 다시 읽어서 최신 상태(내가 손으로 고친 것 포함)를 기준으로 작업함
- 대화 기록은 컴퓨터마다 따로라서 집에서는 이전 대화가 안 보이는 게 정상. 이 문서 + 캔버스 링크만 있으면 됨.
- 브랜드 원본 파일(`1. 텍파_브랜드가이드_디자인가이드` 폴더, AI/PDF)은 **회사컴 다운로드 폴더에만 있음**. 로고·사진·폰트는 이미 캔버스에 올려놔서 보통은 필요 없음. 원본이 필요하면 폴더를 USB/클라우드로 옮길 것.
