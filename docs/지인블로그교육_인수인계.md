## 전체 로드맵 (총 5단계, 목표 = 첫 체험단 + 첫 수익 연결)
1. **주제 고르기** ← 지금 (안내문 + 폼 → 개별 추천)
2. 블로그 세팅 + 첫 글 3개 — **아직 안 만듦. 폼 응답 보고 사람들 주제에 맞춰 만들기로 함**
3. 첫 체험단 (사이트 모음, 신청 요령, 매너, 공정위 문구)
4. 첫 수익 연결 (주제별: 쇼핑커넥트 / 여행 상품 링크 / 애드포스트 준비) — 미션은 "링크 글 1개 발행", 수익 날짜 약속 X
5. 루틴(졸업). 심화(원고료 역제안, 홈판, 클립, 인플루언서)는 원하는 사람만.
- 각 단계 = 짧은 안내문 + 미션 1개 + 단톡방 인증. 무료 대신 조건: 수익·체험단 생기면 단톡방에 인증샷+후기.
