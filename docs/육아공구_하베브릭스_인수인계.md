## 다예님 선호 / 작업 원칙 (이번에 확인된 것)
- 자막은 레퍼런스(희아 @heeah_family) 톤: 흰 **각진** 상자 + 검정 고딕, 이모지 하나. 둥근 상자 X.
- **인스타 잘림 방지**: 사진은 위아래 7% 안쪽, 영상(9:16)은 위 12% ~ 아래 80% 안쪽에만 글씨. 모빌·아기 얼굴 가리지 않기.
- 영상은 **원본 소리 그대로**(크기만 loudnorm), **원본 HDR 색 그대로** (SDR 변환·3:4 여백은 해봤다가 원복 요청받음).
- 윈도우 기본 이모지 😄🥲는 입이 진분홍이라 화나 보임 → 해당 이모지는 `<span class="emo">`(Noto Color Emoji)로.
- 수정 요청이 계속 들어오니 **요청한 장만** 고쳐서 `수정본 3`에 덮어쓰기. 전체 일괄 변경은 먼저 묻기.
- 파일이 탐색기에서 열려 있으면 덮어쓰기 실패 → 다른 이름으로 저장하고 알려주기.
