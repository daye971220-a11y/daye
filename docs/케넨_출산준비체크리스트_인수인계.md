## 기능과 파일
- `dist/index.html`: 구조/문구/링크
- `dist/content.js`: 준비물·7종 사진·참고자료 데이터
- `dist/app.js`: 검색·분류·필터·진행률·체크·제외·공유·인쇄
- `dist/benefits.js`, `dist/guides.js`: 혜택 데이터·탭·필터·저장
- `dist/styles.css`, `theme.css`, `guides.css`: 기존 디자인
- `dist/assets/`: 사이트에 쓰는 이미지
- `.openai/hosting.json`: 기존 프로젝트 ID 및 static dist 설정 보존
- 빌드 없는 정적 사이트. 사이트 작업은 설치된 Sites 스킬로 소스 열기→수정→검수→helper 저장/패키징→native save/deploy 순서.
- 체크 저장 키: `kennen-baby-checklist-v1`, 혜택 키: `kennen-benefits-checklist-v1`. 기존 항목 ID를 바꾸지 않아 이전 체크 유지.
- 체크 내용은 **기기·브라우저별 localStorage**다. 사이트는 집에서 열 수 있지만 회사에서 체크한 상태가 집으로 자동 동기화되지는 않는다.
- 옛 `#product-*` 및 `#deals` 주소는 `#campaign`으로 이동하도록 처리했다.
