1. **첫 1~2초 훅은 셋 중 하나**: ① 돈 숫자(530만원, 5천만원, N백만원 손해, 월 20만원) ② "모르면 손해/아직 아무도 몰라요" ③ 누가 만들었는지(임신 2회차 엄마, 극J 엄마)
2. **자료 화면을 그대로 보여주고 특징을 태그로 하나씩 띄운다** (rouny·hazzang·esse). "사용시기 / 필수여부 / 수량 / 체크·완료 표시"처럼 보는 사람이 "나도 저거 필요해"라고 느끼는 기능 위주.
3. **자막은 짧게 끊어서 컷마다 한 구절** (bom.dong). 1~1.5초 컷, 일상·아기·택배 장면 위에.
4. **아기 얼굴로 마무리 + 댓글 키워드 하나** ('분유', '구글시트', '선물', '출산 준비'). 댓글률 5~9%는 전부 키워드 CTA가 있다. CTA가 없으면(시란빵) 조회수가 높아도 댓글은 0에 가깝다.
5. 길이는 **7~25초**. 숫자형은 7~10초, 자료 소개형은 20~25초.
6. 캡션 첫 줄에 희소성("[공유마감]", "공유 중단합니다")이나 저장 유도("일단 저장하고 보기").

**케넨에 맞게 바꿀 점**
- 케넨님 실제 이야기가 있다: **조산이라 출산준비를 제대로 못 했고**, 급한 대로 쿠팡·네이버에서 샀다가 나중에 공구가 더 싼 걸 알고 속상했다(공구예고 캡션·프로필). 이걸 훅으로 쓰면 다른 계정과 차별된다. 지어낸 경험은 쓰지 않는다.
- 링크는 인스타 본문에서 클릭이 안 되니 **댓글 키워드 → 자동 DM으로 두 링크 전송**(기존 '알람' 댓글 → DM 방식과 같음). 프로필 링크에도 같이 걸어두기.
