## 5. 작업 규칙 (회사컴 메모리에서 옮김 — 꼭 지킬 것)
**표지(썸네일) 확정 기준** — 기준 이미지: 베이비룸 최종 1번 장, 코드: `docs/도노도노_베이비룸/build.mjs` 1번 장
- 흰 띠 라벨 없이 3줄을 **화면 정중앙**(top:50%, translateY(-50%)). 위치가 왔다 갔다 하면 안 됨
- 1줄 브랜드("도노도노") 흰 글씨+그림자 / 2줄 **제품명을 분홍 상자(#E0337A)에 흰 글씨** / 3줄 "최저가 공구예고" 흰 글씨+그림자. 모두 Noto Sans KR 900, 118px
- 프로필 그리드로 작게 봐도 무슨 공구인지 보여야 함(대표님 요청). 사진은 제품이 알아보이고 아기 얼굴이 보이는 컷
- 저장 유도 태그(📌)가 필요하면 어두운 상자에. 분홍 상자 위에 📌를 올리면 핀이 묻힘
- 이미 올라간 표지는 소급해서 고치지 않음

**말투(카피)** — 쓰기 전에 게시본 두 개(instagram.com/p/DebmVZ9E5xD 하베브릭스, instagram.com/p/Ded2zBEEVDl 갈이대)를 열어서 톤을 맞출 것
- 제품을 쓴 건 **대표님(케넨님)**. 경험은 다예님께 묻지 말고 대표님 블로그 후기 + 맘카페·구매 후기에서 찾음. 출처 없는 경험은 지어내지 않음
- 자막 하나는 2줄, 한 줄 15~20자. 앞줄은 상황·공감, 뒷줄은 반전·결과 + 이모지. ㅋㅋ, "..", "쏙/쭉/끝" 같은 구어체. 핵심 한 구절만 분홍
- 설명문·보고서 말투("~를 확인했어요", "어린이제품", "~가 중요해요") 금지. 스펙은 체크 카드/VS 카드 한 장에 모음
- 문장은 주어·이유가 이어지게. 다예님이 준 문구는 줄이지 말고 보충 설명("아기가 좀 크고", "그래서")을 살릴 것
- 혜택은 망설임을 정면으로 풀기("추첨 아니고 전원 증정!"), 마지막은 '알람' 댓글 → DM 행동 유도(가격은 비공개, 할인율만)

**사진·배치**
- **제품이 잘 보이는 사진이 1순위.** 이음새·바닥 클로즈업만 이어지면 사고 싶은 마음이 덜 든다는 피드백. 케넨님 사진에 전체 컷이 없으면 공식 상세페이지 연출 사진을 잘라 섞음
- 자막은 아기 얼굴·제품 핵심부를 피함. 특정 물건을 말하는 자막은 그 물건 바로 옆에(예: 강아지 자막은 강아지 옆)
- 위에만 몰지 말고 위·가운데·아래로 나눔. **인스타 4:5 잘림(위아래 약 3% = 40px) 안쪽**에 모든 글씨가 들어가야 함 → 렌더 후 빨간 띠로 확인
- 카드형 장(체크리스트·그리드·구성표)은 위아래 여백 60px, 칸 간격 24px로 균일(flex column + gap). 사진 칸은 크기·배경·구분선 통일
- 세트 안에서 같은 사진 반복 금지. 기존 시안을 업그레이드하는 방향을 선호
- 흰 **각진** 자막 상자 + 검정 고딕(둥근 pill 금지), 이모지는 `<span class="emo">`(Noto Color Emoji)로 — 윈도우 기본 이모지는 깨지거나 화난 얼굴로 나옴
- 스토리·릴스 영상은 원본 소리를 살림

**기타**

- 다른 계정 조사는 내장 브라우저에서 인스타 로그인(다예님이 직접) 후 천천히. 너무 빨리 요청하면 429 제한이 걸림
