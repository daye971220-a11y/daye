## 작업 규칙 (지금까지 해온 방식)
- 노션 파일 업로드 한도는 **약 5MB**. 그보다 큰 파일은 자료실 행만 만들고 `파일명` 칸에 "(용량 — 노션 용량 초과, 구글 드라이브 'sns 자료' 폴더에 올려야 함)"이라고 적어둠.
- 업로드 방법: `notion-create-file-upload` → curl로 POST(파일명에 쉼표·작은따옴표가 있으면 실패하니 간단한 이름으로 복사 후 업로드) → 행 만든 뒤 `update_properties`로 `📎 파일`에 `{"type":"file_upload","file_upload":{"id":...}}` 연결. 업로드 슬롯은 약 5분 뒤 만료.
- 체험단 가이드라인(브랜드 원고 가이드), 개인 서류(근로계약서·원천징수·이의신청서 등)는 공부 자료가 아니라서 올리지 않음.
- FAQ에 강사 조언 중 문제 소지가 있는 것(지어낸 경험 넣기, 출처 생략, 여러 계정으로 규정 우회 등)은 ⚠️로 표시하고 케넨 쪽 원칙과 대비해 적음.
