토스쇼핑 집에서 이어하기 — 2026-10-14

사용자가 여기서 추가 작성·저장을 멈추고, 원고·사진을 집에서 이어볼 수 있도록 저장하라고 명시 요청했다. 이번 묶음에 한해 보관·동기화한다. 다른 원고의 자동 보관 허가는 아니다.

1. 시작: 원고와사진-이어보기.html을 연다.
2. 다예님이 직접 발행한 수뜰리에 데이지 탈취제는 제외한다. 발행글 수정·중복 작성 금지.
3. 실제 작성·네이버 명시 임시저장한 새 원고는 3편이다.
   001 왕십리 칼집돼지 왕구이 2kg 14,330원
   002 베라 300매 미용티슈 6팩 6,000원
   007 맥스앤맥스 소분용기 350ml 12개+700ml 8개 5,950원
   세 편 모두 저장 뒤 본문을 다시 열어 제목·사진 위치·구매 링크를 확인했다. 17:35 이후 목록에 세 편이 표시됐고 전체 64개였다.
4. 조사 목록 170개는 원고 170편이 아니다. 003 보쌈김치는 후속 확인 시 품절로 제외. 나머지 166개는 아직 미작성. 재고는 바뀌므로 다음 작업 때 다시 확인한다.
5. 상품 기본 조건은 각 상세 화면을 실제 읽어 facts-complete.json에 기록했다. 상세 이미지의 모든 글씨·주장을 정밀 검증했다는 뜻은 아니다.
6. 상품사진은 실제 페이지에서 관찰한 판매자 이미지 670개를 전달용 JPEG로 변환했다. 155번 첫 2개는 다운로드 형식 문제로 빠졌다. 여러 상품은 사진 5장 미만이며 아직 긴 이미지의 의미별 캡처·전수 시각 검수가 남아 있다. 완료 원고의 사진 번호와 조사 사진 순서가 서로 다른 부분은 다음 작업에서 맞춘다.
7. 조사 번호 001~026 중 품절 003을 뺀 25개 구매자용 링크가 public-links.json에 있다. 로그인 필요한 sharelink 관리 주소를 공개 구매 링크로 사용하지 않는다. 집에서 링크 목적지·상품·옵션을 다시 대조한다.
8. 다음에는 004 똑순이 알고니 알탕부터 이어간다. 005 감자탕, 006 궁채, 008 패치 순서. 이미 저장한 001·002·007은 중복 작성하지 않는다.
9. 문체: 이 폴더의 케넨-분석과작성기준.txt 맨 앞에 있는 토스 3개 실제 본문 분석을 먼저 읽는다. 가격·수량·무료배송의 놀라움→상품별 생활 쓰임과 선택 이유→가까운 구매 링크. 설명서를 길게 풀거나 기술적인 검사 수치를 넣지 않는다. ㄷㄷ·ㅋㅋ는 맥락에 맞게. 제조·맛·사용·구매·가족 반응을 꾸미지 않는다. 쿠팡보다 싸다/최저가/미래 품절·인상은 직접 근거가 있을 때만 쓴다.
10. 최저가보상·내일도착·늦으면보상은 실제 표시 상품만 넣는다. 내일출발과 내일도착을 구분한다. 최대할인가 표시 금액은 누구나 확정 결제하는 가격으로 만들지 않는다. 개당 수익은 판매가가 아니다.
11. 네이버에는 글만 입력·임시저장하고 사진 번호와 위치를 표시한다. 사진은 따로 전달하며 업로드는 다예님이 한다. 발행 요청은 없었다.
12. 임시저장 기존 글은 삭제·덮어쓰지 않는다. 다예님이 탈취제를 직접 발행하셨다고 확인했다. 에이전트가 다시 만든 17:21 탈취제 중복 임시저장본은 사용자가 집에서 정리하겠다며 그대로 두라고 해서 삭제하지 않았다. 이 묶음에서는 제외했다. 발행글을 수정하거나 다시 만들지 않는다.
13. 이 폴더만 기존본 교체로 이어서 작업한다. 불필요한 원고 이력 폴더를 추가하지 않는다.
